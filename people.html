看看谁也在一个人开公司

这里收录主动登记上来的 OPC：做什么、在哪个赛道、到什么阶段、怎么找到他。 公开什么、公开到什么程度，完全由你自己决定——不想留联系方式也可以只留一个站点。

把你的 OPC 登记上来

两种方式任选，都通过 GitHub 完成，公开、可追溯、可随时撤回。登记后你会出现在下方列表里。

1提 Issue（最快，推荐）

点开表单逐项填写即可，无需懂 Git。维护者核实后会合并进登记簿。

打开登记表单 →

2提 Pull Request（可批量 / 可改格式）

直接编辑 people.json， 在 items 数组末尾追加一条，提交 PR。

在线编辑 people.json
填写字段说明与 JSON 模板（点击展开）
name昵称 / 品牌名 / 团队名。可以是化名，不要求真实姓名。
intro必填。40–120 字简介：你做什么、为谁解决什么问题、做到什么程度。
track赛道，如 内容创作 / 电商出海 / 垂直智能体 / 设计服务 / 开发者工具 / 咨询交付。
city所在城市。只写到城市即可，不要填详细地址。
stage阶段：想法期 / 已上线 / 已营收 / 已盈利。
contact必填。联系方式或站点，至少一项：邮箱 / 个人主页 / GitHub / 产品链接。 建议优先留公开站点，避免把私人手机号写在公开仓库。
tags3–6 个关键词，便于被检索到。
consent必须为 true。表示你同意公开以上信息。
{
  "id": "",
  "name": "你的昵称 / 品牌名",
  "intro": "40-120 字：你做什么、为谁解决什么问题、做到什么程度。",
  "track": "内容创作",
  "city": "杭州",
  "stage": "已营收",
  "contact": "https://your-site.example 或 you@example.com",
  "tags": ["AI 写作", "独立开发", "出海"],
  "consent": true,
  "addedAt": "2026-09-21"
}
id 不用自己填（留空即可），合并时由维护者按现有最大序号 +1 分配。 提交前请把 addedAt 改成当天日期。

① 公开范围由你定：登记即等于公开发布。不想被联系就只留站点，不想留真名就用品牌名或化名， 城市只写到市级。请勿提交他人信息。
② 这里是公开仓库，不是私密表单：Issue 与 PR 内容对全网可见，且会留在 Git 历史里。 不要填写手机号、身份证、住址等敏感信息；如果确实需要撤回，可提 Issue 说明，维护者会删除对应条目， 但请理解历史记录可能仍可被检索到。
③ 不背书、不收费：本站只做信息聚合，不对任何登记主体的资质、业绩、履约能力作担保， 也不参与任何交易撮合与收费。请自行尽调，注意风险防范。
